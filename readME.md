# Обучающий проект для изучения ООП в Python

## Описание:

Проект представляет из себя сервис для поиска вакансий.

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/Rayour/VacancySearch.git
```
2. Установите зависимости:
```
poetry instal 
```
